Runtime leases

Scheduling workers

Workers coordinate ownership of a scheduled task before executing it.

The worker checks its lease before renewing ownership. See the renewal window for timing details.

An expired token prevents a paused worker from renewing ownership.

Configuration

Use a bounded queue and retry transient network failures with backoff.

Failure recovery

Quorum recovery requires three healthy workers before the scheduler accepts a new owner.

const active = worker.lease.isValid();

Glossary

lease
A time-limited ownership token issued by the scheduler. This definition is far from the selected word.

Renewal timing

Renewal must arrive before the clock deadline. The grace period is 250 milliseconds.

Other meanings

A building lease is a rental contract. This unrelated use must not replace the worker scheduling sense.
